# ShowDoc SQL 注入 (3.2.5-sqli)

## 指纹特征
- 服务: ShowDoc <= 3.2.5
- 端口: 8080 (默认)

## 利用矩阵
| 触发方式 | 路径 | 权限要求 |
| :--- | :--- | :--- |
| SQL 注入 | `/index.php` | 无 (需利用脚本) |

## PoC 指令

通过在请求参数中注入 SQL 语句并结合特殊逻辑获取 token 或密码 hash。

```bash
python3 poc.py -u http://{{TARGET}}:8080
```

## Success Signal
- **数据泄露**: 成功从数据库导出用户表或管理员 Token/Hash。
- **状态验证**: 成功获取数据库交互权限。
