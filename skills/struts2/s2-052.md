# S2-052 Struts2 远程代码执行 (CVE-2017-9805)

## 指纹特征
- 服务: Apache Struts2 (2.1.2 - 2.3.33, 2.5 - 2.5.12)
- 场景: REST 插件使用 XStream 处理 XML

## 利用矩阵
| 触发方式 | 路径 | 权限要求 |
| :--- | :--- | :--- |
| REST XML 反序列化 | `/*.xhtml` 或 `/*.json` | 无 |

## PoC 指令

## Success Signal
- **状态验证**: 后端成功反序列化并执行命令。
- **物理验证**: 检查系统是否执行了预期操作（如 `touch /tmp/success`）。
