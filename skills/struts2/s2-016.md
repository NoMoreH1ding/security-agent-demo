# S2-016 OGNL 注入 RCE

## 指纹特征
- 服务: Apache Struts2 (2.0.0 - 2.3.15)
- 协议: HTTP (Redirect 动作触发)

## 利用矩阵
| 触发方式 | 路径 | 权限要求 |
| :--- | :--- | :--- |
| redirect/redirectAction 注入 | `/*.action?redirect:{{OGNL}}` | 无 |

## PoC 指令
