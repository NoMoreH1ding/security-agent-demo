# S2-057 OGNL 注入 RCE (CVE-2018-11776)

## 指纹特征
- 服务: Apache Struts2 (<= 2.3.34, 2.5.16)
- 条件: `alwaysSelectFullNamespace` 设置为 true 且 Action 映射配置中未使用 namespace 或使用通配符

## 利用矩阵
| 触发方式 | 路径 | 权限要求 |
| :--- | :--- | :--- |
| Namespace OGNL 注入 | `/{{OGNL_EXPRESSION}}/{{ACTION}}.action` | 无 |
