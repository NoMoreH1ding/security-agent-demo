# kkFileView ZipSlip RCE (4.3-zipslip-rce)

## 指纹特征
- 服务: kkFileView < 4.4.0-beta
- 端口: 8012 (默认)
- 条件: 可上传并预览恶意 ZIP 文件

## 利用矩阵
| 触发方式 | 路径 | 关键点 |
| :--- | :--- | :--- |
| ZipSlip 路径遍历写入 | `/fileUpload` | 预览 ZIP 时解压文件名过滤不当 |

## PoC 指令

通过构造包含恶意文件路径（例如：`../../../../tmp/success`）的压缩包实现任意文件写入。

**1. 准备恶意压缩包**
使用工具或脚本创建包含路径遍历的 `test.zip`：
- 文件名设置为 `../../../../tmp/success` 或其他可覆盖路径。

**2. 触发预览**
- 上传并预览 ZIP 文件。
- 接着点击预览内部其他合法文件（如 `sample.odt`）以触发整体的解压与文件操作逻辑。

## Success Signal
- **物理验证**: 目标服务器的对应路径（如 `/tmp/success`）成功创建了文件。
| 关键漏洞点 | 说明 |
| :--- | :--- |
| ZipSlip | 文件解压过程中对文件名未进行安全校验，允许目录穿越写入 |
